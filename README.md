# Engineering Toolkit

A command-line unit conversion and data analysis toolkit built in Python.

## Features

- Length, temperature, pressure, force and torque conversions
- Step-by-step conversion chain output
- CSV sensor data processing and analysis (Phase 3)

## Setup

**1. Clone the repo**
```bash
git clone git@github.com:sMina1/engineering-toolkit.git
cd engineering-toolkit
```

**2. Create and activate a virtual environment**
```bash
python -m venv .venv
source .venv/bin/activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

## Running Tests

```bash
pytest tests/ -v
```
